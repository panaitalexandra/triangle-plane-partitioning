# Point Position Relative to a Triangle

## 1. Requirement

Given a triangle **ABC** defined by the coordinates of its vertices:
* **A**(x_a, y_a)
* **B**(x_b, y_b)
* **C**(x_c, y_c)

The objective is to determine the position of a point **M**(x_m, y_m) relative to the triangle, based on the partition of the plane generated by the lines supporting the triangle's sides (AB, BC, and AC).

### Methodology
The plane is divided into seven distinct regions by extending the lines of the triangle's edges. To classify the position of point **M**, we calculate the determinants (signed areas/orientations) associated with point **M** and each pair of vertices:
* **Det(ABM)**
* **Det(BCM)**
* **Det(CAM)**

The combination of signs (+, -, or 0) of these determinants allows us to pinpoint exactly which region **M** occupies (inside, on an edge, on a vertex, or in one of the external regions).

---

## 2. Practical Example

Consider the following coordinates:
* **A** = (5, 10)
* **B** = (2, 3)
* **C** = (10, 3)
* **M** = (5, 5)

### Analysis
By extending the lines formed by segments **AB**, **BC**, and **AC**, the entire 2D plane is partitioned. Point **M** is then evaluated against these boundary lines.

In this specific case, with **M(5, 5)**:
1. We calculate the orientation of **M** relative to line **AB**.
2. We calculate the orientation of **M** relative to line **BC**.
3. We calculate the orientation of **M** relative to line **AC**.

If all determinants have the same sign, point **M** is located **inside** the triangle.
